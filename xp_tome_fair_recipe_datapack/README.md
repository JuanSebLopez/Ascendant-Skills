XP Tome - Fair Recipe
Minecraft 1.21.1 - NeoForge

This datapack overrides the XP Tome recipe from the XP Tome mod.

Recipe:
E P A
Y B Y
A P E

A = Amethyst Shard
B = Book
E = Echo Shard
P = Ender Pearl
Y = Eye of Ender

Cost:
- 1 Book
- 2 Ender Pearls
- 2 Eyes of Ender
- 2 Echo Shards
- 2 Amethyst Shards

Technical notes:
- XP Tome mod id is xpbook.
- Minecraft 1.21.1 uses data/xpbook/recipe/xp_tome.json, not data/xpbook/recipes/xp_tome.json.
